# For You, Always 💕

A romantic static website — an apology and a second chance, made with love.

## Preview Locally

Open `index.html` in your browser, or run a simple server:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080)

## Deploy on GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Under **Source**, select **Deploy from a branch**
4. Choose **main** branch and **/ (root)** folder
5. Click **Save** — your site will be live at `https://<username>.github.io/<repo-name>/`

## Personalize It

Edit `index.html` and replace:

- **"My Love"** → her name (hero section)
- The apology letter text → your own words
- The "Why You're My Everything" cards → your personal reasons
- The promises → what you want to commit to
